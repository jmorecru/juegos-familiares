# Juegos Familiares

Colección de juegos para jugar en familia desde el navegador.

## Qué hace
_Por definir: qué juegos incluye y para qué edades._

## Cómo funciona por dentro
- `index.html`: página de entrada.
- `styles.css`: estilos.
- `js/main.js`: lógica.

Sin frameworks ni build: el navegador carga los ficheros tal cual.

## Cómo ponerlo en marcha
1. Abre `index.html` en el navegador, o arranca un servidor local:
   ```
   python -m http.server 8000
   ```
   y entra en http://localhost:8000.
2. Publicación: GitHub Pages desde la raíz de `main`.
